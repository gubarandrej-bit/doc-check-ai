# DocCheck — система проверки документации по НТД

## Быстрый старт

### Системные требования
- Docker & Docker Compose
- Node.js 20+ (для фронтенда)
- Python 3.12+ (для бэкенда)

### Установка
#### Вариант А: Одиночный скрипт (рекомендуется)
```bash
sudo bash install.sh [--with-oda] [--with-models] [--no-start]
```

#### Вариант Б: Вручную
```bash
# 1. Клонируйте репозиторий
```

```bash
# 2. Установите зависимости бэкенда
```
```bash
cd backend && pip install -r requirements.txt
```

```bash
# 3. Установите зависимости фронтенда
```
```bash
cd frontend && npm install
```

#### Ключи скрипта `install.sh`

| Аргумент | Действие |
|---|---|
| `--with-oda` / `-WithOda` | после базовой установки автоматически пытается установить ODA File Converter и скопировать его в tools/oba |
| `--with-models` / `-WithModels` | после запуска скачать бесплатные модели в Ollama |
| `--no-start` / `-NoStart` | только установить, не запускать |
| `--skip-node` (только `sh`) | не устанавливать Node.js |
| `--skip-python` (только `sh`) | не устанавливать Python |
| `--help` / `-?` | справка |

### После установки

Система будет доступна по адресам:

| Адрес | Описание |
|---|---|
| `http://localhost:80` (производство) | Главная страница, OAuth, загрузка файлов |
| `http://localhost:5173` (разработка) | Vite dev server |

> **⚠️ Тела запроса:** Максимальный размер тела запроса — 512 МБ (настроено в nginx.conf). При превышении возвращается 413.
>
> **⏱ Таймауты:** nginx настроен на 900 секунд (15 минут). Длинные операции конвертации DWG могут занять это время.
>
> **Dev vs Production:** При `npm run dev` Vite работает на порту 5173 с Vite-протоксом к бэкенду. В production Docker запускается nginx на порту 80, который проксирует `/api` → backend:8000. Переменная `VITE_API_URL` не нужна — прокси работает прозрачно.

### Вариант с ODA File Converter

Если передать флаг `--with-oda` (или `-WithOda`), скрипт будет:
1. Искать файл `ODAFileConverter*.deb` в текущей директории
2. Если найден — устанавливать через `gdebi` или `dpkg`
3. Копировать `ODAFileConverter` в `tools/oba/`
4. Перезапускать бэкенд Docker

Если файл не найден, скрипт выведет инструкцию по ручному установлению.

> **Лицензия:** ODA File Converter — это сторонняя программа Open Design Alliance. Скачивайте её с <https://www.opendesign.com/guestfiles/oda_file_converter>. Принятие условий лицензии требуется перед использованием.

### Чертежи DWG

Для работы с DWG-файлами:
1. Установите ODA File Converter (см. выше)
2. Положите `.deb` файл в ту же директорию, где `install.sh`
3. Запустите `sudo bash install.sh --with-oda`
4. Чертежи DWG будут автоматически конвертироваться в DXF и станут доступны для анализа

Без ODA-файла:
- `CAD_STRUCTURE` вернет `not_performed` с причиной
- DWG не конвертируется
- Альтернатива: экспортировать DWG в DXF/PDF вручную

### Без ODA
Если ODA не установлен, система все равно работает с DXF, PDF, DOC/DOCX, XLSX файлами. DWG требует ODA.

## Чертёжи (DWG / DXF)

### Вариант с ODA File Converter

С флагом `--with-oda` скрипт автоматически установит ODA File Converter и скопирует его в `tools/oba/`. После этого:

1. Загрузите DWG-файл через интерфейс
2. Плагины `CAD_STRUCTURE` и `AI_CAD_VISION` автоматически конвертируют DWG в DXF
3. Структурный разбор требует ODA File Converter
4. Vision-разбор требует мультимодальную модель + ODA для конвертации DWG

Без ODA-файла:
- `CAD_STRUCTURE` вернет `not_performed` с причиной
- DWG не конвертируется
- Альтернатива: экспортировать DWG в DXF/PDF вручную

### Без ODA
Если ODA не установлен, система все равно работает с DXF, PDF, DOC/DOCX, XLSX файлами. DWG требует ODA.
