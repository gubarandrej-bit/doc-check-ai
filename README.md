# DocCheck

Система проверки и глубокого анализа проектной и рабочей документации
по инженерным системам зданий на соответствие нормативно-техническим
документам (НТД) Российской Федерации.

**Охват систем:** электроснабжение, электроосвещение, противопожарные системы
(пожарная сигнализация, СОУЭ, пожаротушение), сети связи (СКС, ЛВС, ВОЛС),
видеонаблюдение, СКУД, охранная сигнализация, АСУ и АСУТП.

## Быстрый старт

```bash
git clone https://github.com/gubarandrej-bit/doc-check-ai.git
cd doc-check-ai
sudo bash install.sh       # Linux / Proxmox
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт устанавливает Docker, Node.js, npm, Python, создаёт `.env`
со случайным ключом и запускает систему. Веб-интерфейс — на порту 80.

**Вход по умолчанию:** `admin` / `admin123` (смените после первого входа).

Подробная инструкция — в [INSTALL.md](INSTALL.md).

## Адреса и единая точка входа

Контейнер фронтенда запускает nginx: он отдаёт собранный интерфейс и
одновременно проксирует запросы `/api/*` на бэкенд. Поэтому интерфейс и API
живут на одном адресе и браузеру не мешает CORS.

| Что | Адрес |
| --- | --- |
| Веб-интерфейс | `http://<адрес-сервера>/` |
| API | `http://<адрес-сервера>/api/...` |
| Swagger (OpenAPI) | `http://<адрес-сервера>:8000/docs` |
| Проверка живости | `http://<адрес-сервера>/health` |

Порт 8000 бэкенда открывать наружу не обязательно: интерфейс ходит к нему
внутри сети Compose.

Два параметра настроены осознанно и менять их без нужды не стоит:

- `client_max_body_size 512m` в `frontend/nginx.conf` — стандартных 1 МБ
  не хватает для загрузки xls, doc, pdf и dwg;
- `proxy_read_timeout 900s` — анализ документа нейросетью идёт минутами,
  стандартные 60 секунд обрывали бы соединение на живом запросе.

При разработке (`npm run dev`) проксирование `/api` выполняет сам Vite —
отдельный nginx для этого не нужен, он нужен только в рабочем режиме.
