# doc-check-ai

Система автоматизированной проверки проектной и рабочей документации по инженерным системам (электроснабжение, электроосвещение, противопожарные системы, сети связи, видеонаблюдение, СКУД, охранная сигнализация, АСУ/АСУТП) на соответствие действующим НТД РФ.

## Режимы работы
локальный / облачный / гибридный.

## Быстрый запуск
```bash
cd doc-check-ai
cp backend/.env.example backend/.env
docker compose up -d --build
http://localhost:80
```
